Help & Troubleshooting

How recording works
  1. Press Enter (or tap the mic button) to start recording. The button turns red and shows a waveform.
  2. Press Enter again to stop. The audio is automatically saved to local storage as a backup.
  3. Transcription begins immediately — the audio is sent to the server, which forwards it to the configured transcription API (e.g. Whisper).
  4. Auto-cleanup (if enabled) sends the raw transcript to a second API for grammar fixing, punctuation, and formatting.
  5. The cleaned result is automatically copied to your clipboard and saved to history.
Transcription engines (Whisper vs Gemini)

The app supports two transcription engines, chosen from the Engine dropdown in Settings > API Configuration. Each engine uses its own API key, so you can switch freely without losing your other configuration.

  • Whisper-compatible — works with any provider that exposes the OpenAI-style /audio/transcriptions endpoint: Mistral Voxtral, OpenAI Whisper, Groq, and others. This is a dedicated speech-to-text model. Configure its API key, base URL, and model (e.g. voxtral-mini-latest).
  • Gemini (Google) — uses Google's native Gemini API. Gemini is a multimodal LLM, so audio is sent inline and transcribed with a "transcribe verbatim" prompt. Configure its API key and model (e.g. gemini-2.5-flash). This is often much cheaper than dedicated speech models.

Key differences:

  • Cost — Gemini bills per token (audio tokenizes very efficiently), so it's typically far cheaper per minute than Whisper-compatible models that bill per minute of audio.
  • File size limit — Gemini accepts inline audio up to ~20 MB (roughly 10–20 minutes of speech). Whisper-compatible engines accept up to the app's 50 MB cap. For typical dictation this won't matter, but very long single recordings may need the Whisper engine.
  • Language & vocabulary hint — both engines respect the Language and Vocabulary hint fields in Settings.

Note: The Gemini transcription key is separate from the Cleanup key — even if you use the same key for both, enter it in both fields. This lets you use different providers for transcription and cleanup if you want.

Append mode

Enable the Append toggle on the record tab to accumulate multiple dictation segments into one growing transcript.

  • Each new recording is transcribed and cleaned individually (only the new segment uses API credits), then appended to the accumulated text.
  • Tap the transcript to copy the entire accumulated text to your clipboard.
  • The accumulated transcript starts fresh on each page load — no stale text carries over from previous sessions.
  • If you toggle Append on mid-session, whatever's currently on screen is captured as the starting point.
  • Click Clear to reset the entire accumulated transcript.
  • Turning off Append switches back to single-segment view. The accumulated text is still saved and reappears when you toggle Append back on.
Live transcription

The Live toggle on the record tab changes how recording is transcribed. It is off by default.

  • Live OFF — the app records the whole thing and transcribes it only after you stop (the default behavior).
  • Live ON — while you record, the audio is sent in ~10-second chunks and each chunk is transcribed as you go. This is designed for long dictation sessions (1–2 minutes or more): by the time you stop, most of the audio has already been transcribed during recording, so you don't wait for the whole transcription at the end.
  • Why 10 seconds? Longer chunks mean far fewer chunk boundaries than 3-second chunks, which greatly reduces the chance of a word being cut off at a boundary. The trade-off is that text appears every ~10 seconds rather than instantly.
  • Note: Live mode transcribes the same total audio, so API cost is roughly comparable (it may use slightly more due to chunking); it's mainly a wait-time trade for long dictations.
Word count

Above the transcript, a small line shows the word count of the current text, e.g. "89 words".

Custom prompts

You can configure up to 4 custom cleanup prompts in addition to the built-in Default prompt. Manage them from the Cleanup Prompts section in the Settings tab.

  • Each prompt is a system message sent to the cleanup model — use it to control formatting, tone, or style.
  • Select the active prompt from the dropdown on the Dictate tab. The dropdown is always visible regardless of the Auto-clean toggle.
  • Switch prompts instantly using keyboard shortcuts 1 through 5 (by position: 1 = Default, 2–5 = custom).
  • You can edit the Default prompt — click Edit next to it. Use Restore to revert to the built-in version.
  • Prompts are stored on the server and persist across devices.
  • You can re-clean a transcript with a different prompt at any time using the Clean up button — even if Auto-clean already processed it.
Streaming cleanup

When your cleanup API supports streaming (most OpenAI-compatible providers do), the cleaned text appears progressively as it's generated — you don't have to wait for the full response.

  • A blinking cursor appears in the transcript area while streaming is in progress.
  • The elapsed processing time is shown in the status bar during transcription and cleanup.
  • If streaming fails, the app automatically falls back to the standard (non-streaming) cleanup.
  • You can cancel mid-stream — any partial text received so far is kept on screen.
Uploading audio files

Click the Upload button (or press U) to select an audio file from disk. Supported formats include MP3, WAV, OGG, WebM, M4A, FLAC, AAC — any audio format your browser supports. The maximum file size is 50 MB. Larger files will show an error message.

Keyboard shortcuts
  • Enter — Start / Stop recording
  • Esc — Cancel recording / abort processing / clear text (also closes modals and popovers, exits transcript editing)
  • P — Pause / Resume recording
  • C — Copy transcript to clipboard
  • E — Edit transcript (fix words before copying); press Ctrl/Cmd+Enter or Esc to finish (same as Done)
  • Z — Undo clear (restore last cleared transcript)
  • K — Clean up (re-process transcript with selected prompt)
  • R — Toggle raw / cleaned view
  • N — New recording (clear + start)
  • U — Upload audio file
  • A — Toggle append mode
  • T — Toggle auto-clean
  • 1–5 — Switch cleanup prompt by position
  • L — Toggle live transcription
  • M — Toggle light/dark theme
  • D — Dictate tab
  • H — History tab
  • S — Settings tab

Shortcuts are disabled when typing in input fields. On desktop, click Shortcuts in the header for a quick reference.

Offline usage

This app works as a Progressive Web App (PWA). When you're offline:

  • You can still record audio — the mic works without a connection.
  • Transcription will fail until you're back online. The recovery bar will appear with a copy of your recording.
  • When you reconnect, tap Retry to send the saved recording for transcription.
  • An orange banner at the top shows your connectivity status.
Local storage & data
Recording backup Audio recordings are stored in your browser's IndexedDB (database: dictationAudioBackup). If IndexedDB is unavailable (private browsing), the audio is kept in memory as a fallback. Backups are automatically deleted after successful transcription.
Session history Your last 20 transcriptions are saved in localStorage under dictationHistory. The raw and cleaned text are stored here — not the audio. Use Clear All in the History tab to delete them.
Settings & preferences API keys are stored on the server in the data/settings.json file. Your theme selection, auto-clean toggle, append mode, and active prompt are stored in localStorage.
Accumulated transcript When Append mode is enabled, the combined transcript is stored in localStorage under accumulatedTranscript. It is cleared on page load to start each session fresh.
Clearing data Use the Clear button on the record bar to clear the current transcript, any audio backup, and the accumulated transcript (if in append mode). Use Clear All in History tab to remove all saved transcriptions. Server data persists until you overwrite it.
Error messages & what to do
Microphone access denied Your browser blocked the microphone. Check your browser permissions for this site and allow microphone access. Reload the page after granting permission.
Upload: 413 The recording is too large (over 50 MB). Try a shorter recording or reduce the audio quality. If using a reverse proxy, check its client_max_body_size setting.
Upload: 4xx / 5xx The server could not process your audio. This may be a temporary issue — try again. If it persists, check the transcription API key in Settings.
Transcription API key not configured Go to Settings > API Configuration and enter your transcription API key. The key is stored on the server and never exposed to the client.
Cleanup API key not configured Go to Settings > API Configuration and enter your cleanup API key if you want auto-cleanup. You can also disable auto-cleanup using the toggle.
Cleanup failed The raw transcript was successfully transcribed and copied to your clipboard, but the cleanup step failed. Press K or click Clean up to retry.
Transcription failed The audio was saved as a backup. A recovery bar appears with Retry (re-upload the saved audio), Download (save the audio file locally), and Clear (dismiss).
Audio file too large The uploaded file exceeds 50 MB. Upload a shorter or smaller file, or record directly with the mic button.
No saved recording The recovery bar appeared but no backup exists. This can happen if IndexedDB storage was cleared or is unavailable (e.g. private browsing with restrictions).
Unauthorized Your session has expired. You'll be redirected to the login page. Log in again to continue.
